# Pong

A simple, responsive browser Pong game built with vanilla HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser, then click **Start Game**.

- Move the left paddle with your mouse or the **↑ / ↓** arrow keys.
- The computer controls the right paddle.
- First to 5 points wins.
- Press **Space** to pause or resume.

No build tools or dependencies are required.
